## Rig levers confirmed by reading `proxy.cpp` (needed by the script)

* `near:<sub>` matches actor instance name OR class name, case-insensitive substring
  (`RigNameMatches`), refuses classes containing Manager/Subsystem/Component/State/Data, and
  refuses a target whose level is not shown.
* `RigStandBeside` offset clamp is **40 cm minimum**, +150 cm in Z — a "stand ON the lift" hop
  must use `qd.near=40`.
* `qd.trigger = <Name>@<Area>#nonce` dispatches a placed volume's own begin event; a spawner
  resolves through `trig::IsSpawner` (slot 4).
* `qd.attack = <action>[,gap_ms][,count]` calls every `InpActEvt_<action>*` (the pawn declares
  `InpActEvt_Attack` twice; the first does nothing).
* `qd.audit` forces a pass; `qd.auditfork = <flag>=<value>` / `clear` is the test-only
  divergence lever (`DevAuditLever`, proxy.cpp:28366).
* Shipped `qdcoop.ini` measured today: `DesyncAudit=1 AuditMs=10000`, `BossPhaseSync=0`,
  `WorldSetSync=0`, `PuzzleSync=0`, `HazardSync=1`, `DamageBothWays=1`, `InteractSync=1`.

## Script design (`session-p1.ps1`)

Phases, each one boot pair (a launched game does not survive its command — R14):

* `audit` — clean pair → `audit: OK N categories, M items`; `qd.auditfork QDAuditProof=1` on the
  **peer** → exactly one `audit: DESYNC flags QDAuditProof host=… peer=…`, no other flags row;
  `clear` → `audit: flags healed`; plus relay `malformed total=0`.
* `hub` — R4 Arjaot (peer talks), R5 Ekonta (host talks), R6 barricade (peer breaks), R7
  Checkpoint rest (host), R8 `Teleporter_GR` (peer).
* `dungeon` — R9 key in `110_GR_dungeon` then gate in `100_GR`, R10 player on `IntroDungerLift_BP2`
  + `qd.mover`, R11 `120_GR_goldenroom`, R12 `125_GR_CubeHall`, R13 `130_GR_outerisles`.
* `shopboss` — R14 merchant + shop door + purchase/key-stock contract, then B1/R15 with
  **god mode removed** and real `qd.attack` swings on both machines.
* `intro` — R1–R3 from an empty save dir (title screen), menu driven by posted keys/clicks
  (`-MenuKeys`, `-MenuFrac` so the coordinates can be corrected from the screenshot).
